# Jump Loot

A Minecraft Java Edition mod for Forge 1.20.1.

## Development environment

- Minecraft: 1.20.1
- Forge: 47.2.0
- Java: 17
- Mod ID: `jumploot`

## Current status

Initial project scaffold. Gameplay systems are not implemented yet.

## Build

Use a Java 17 JDK and Gradle:

```bash
gradle genIntellijRuns
gradle build
```

The built mod jar will be in `build/libs/`.
